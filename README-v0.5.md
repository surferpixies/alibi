# ALIBI v0.5 — splash screen cinématographique

## Nouveautés
- splash screen enrichi avec mots en filigrane;
- apparition graduelle et subtile des mots;
- deux rubans jaunes de type cordon de police en arrière-plan;
- logo officiel ALIBI au centre;
- sous-titre `Une enquête. Plusieurs jours.`;
- durée du splash ajustée pour laisser jouer les animations.
