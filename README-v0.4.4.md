# ALIBI v0.4.4 — logo officiel intégré

Cette version contient désormais le **vrai logo officiel fourni par toi**.

## Le même logo est utilisé partout

- splash screen;
- logo de la page d'accueil;
- favicon navigateur;
- icône écran d'accueil iPhone;
- icônes PWA 192×192 et 512×512.

## Fichiers ajoutés

- `assets/images/logo/alibi-logo.png`
- `assets/images/logo/favicon-32.png`
- `assets/images/logo/apple-touch-icon.png`
- `assets/images/logo/icon-192.png`
- `assets/images/logo/icon-512.png`

Toutes les icônes dérivées ont été générées à partir du fichier exact fourni dans la conversation.

## Après déploiement

Sur Mac/Safari, ferme puis rouvre l'onglet ALIBI. Si l'ancienne icône reste visible, teste en navigation privée ou vide le cache du site.

Sur iPhone, supprime l'ancien raccourci ALIBI de l'écran d'accueil puis ajoute-le à nouveau depuis Safari.
